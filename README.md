# 声物 / SONIC RELICS

让一首歌回到它出生时的机器里，也允许听众把它带去另一个年代。

一个可在本地运行的年代音乐播放器。暖灰纸面、实体设备和真实音频响应组成一座可以把玩的声音博物馆。

作者：[HarrisonDo](https://github.com/HarrisonDo) · [项目仓库](https://github.com/HarrisonDo/sonic-relics) · [署名—非商业许可](./LICENSE)

## 运行

推荐使用 Node.js 22.12+。

macOS 可以直接双击项目内的 **`启动声物.command`**：首次运行会安装依赖，然后启动服务并打开浏览器。如果声物已经运行，会直接打开现有页面。运行期间请保留它打开的终端窗口，按 Control+C 可停止服务。

也可以在终端运行：

```sh
npm ci
npm start
```

打开 <http://127.0.0.1:5173/>。`npm run dev` 仍然可用。当前开发服务固定使用 5173 端口；端口被占用时会明确报错。

### 打不开时

- 浏览器显示“无法连接”或 `ERR_CONNECTION_REFUSED`：本地服务没有运行。双击启动入口或重新执行 `npm start`，看到 `Local: http://127.0.0.1:5173/` 后刷新页面。此前由开发工具启动的临时服务，可能会随终端或应用退出而停止。
- 提示 `Port 5173 is already in use`：先打开上述网址确认是否已是声物。若是其他服务，请在对应终端停止它后重试。
- 不要直接双击 `index.html`；项目需要由 Vite 服务提供页面和资源。
- 如果报错出现在 Codex 会话里，并包含 `The requested item was created under a different Azure OpenAI resource`，这是模型网关对历史请求的资源归属报错。需要网关端将后续请求路由到创建该历史数据的同一 Azure 资源；本地播放器没有调用 Azure/OpenAI，不依赖该会话是否可继续。

```sh
npm test             # 年份、年代边界、播放队列和真实音频标签测试
npm run build        # TypeScript 检查 + 生产构建，输出 dist/
npm run preview      # 在本机预览生产构建
npm run format:check # 检查代码格式
```

## 先玩什么

1. 按磁带机的 PLAY，播放默认的《晚风来信》。
2. 保持歌曲播放，点年代轴切换黑胶、CD、iPod、流媒体或脑机芯片：旧设备会裂开、炸成碎片，再在新年代重新拼合，进度一直继续。
3. 在黑胶唱机上，把唱臂拖到唱片上落针；落在越靠内圈的位置，就从越靠后的地方开始播放。
4. 打开「声音收藏」切歌，再点「跟随歌曲年份」，体验自动更换载体。
5. 点「导入音乐」或拖入本地音频。点年份旁的铅笔，可以修正年份。

预置七段由项目脚本合成的原创器乐和原创 SVG 封面。界面明确标为「原创体验片段」「模拟年代」；年份是体验场景设定，不是这些片段的历史发行时间。黑胶演示曲《黄昏舞池》自带合成的唱片底噪，这是这段原创片段本身的质感；导入的音乐始终保持原音。音频和封面的说明见 `public/audio/LICENSE.txt`。

## 九种载体

| 年份 / 入口   | 载体           | 已实现的专属操作                                                     |
| ------------- | -------------- | -------------------------------------------------------------------- |
| 1959 及以前   | 收音机         | 调谐旋钮与刻度拖动选台、松手才换歌、调谐指示灯、音量旋钮、电源       |
| 1960—1979     | 黑胶唱机       | 拖动唱臂落针、落针位置即进度、点唱片任一圈落针、CUE 升降杆、启停惯性 |
| 1980—1989     | 磁带随身听     | 卷轴随进度变化、点按前后十秒、按住 REW / FF 连续卷带、弹仓换带       |
| 1990—1999     | CD 播放机      | 开盖换碟（左右翻看或滑动）、点碟片合盖播放、按住快进快退、启停惯性   |
| 2000—2004     | MP3 播放器     | 单色屏、长歌名滚动、按住方向键快进快退、侧面音量键、真实频谱         |
| 2005—2012     | iPod           | MENU 里转盘选曲、播放界面转盘调音量、按住快进快退、中心键确认        |
| 同期可选      | MP4 播放器     | 封面与频谱切换、屏幕进度条、全屏观看                                 |
| 2013 至今     | 流媒体         | 音频驱动的轮廓波纹、拖动外圈调进度、轻触泛起涟漪、控件静置淡出       |
| 手动「2077?」 | Relic 脑机芯片 | 推入芯片接入播放、拉出拔下暂停、点按切换、神经脉冲                   |

这些分段服务于年代记忆，不表示设备的发明或退场时间。2005—2012 默认 iPod，可在偏好设置中改为 MP4。MP3、MP4 在年代轴中指设备形态，与文件格式无关。Relic 是面向任何歌曲的幻想入口。

自动模式跟随歌曲年份；点击年代轴会进入自由穿越，切歌后仍保留所选载体。每种设备共享同一个音频实例，切换设备不会重启歌曲。

## 音乐与本地保存

- 年份优先级：人工修正 → 原始发行年标签 → 普通发行年标签。
- 无年份时使用中性播放器；不根据文件名、文件修改时间或曲风猜年份。
- 支持读取曲名、艺术家、年份与内嵌封面，以文件内容 SHA-256 去重。
- 本地音频副本和封面保存在 IndexedDB；收藏、年份修正和偏好保存在 localStorage。刷新会恢复音乐库。
- 数据属于当前浏览器和网址。换浏览器、换端口或清除站点数据后不会自动同步；原始音频文件始终由用户保管。
- 单个文件上限 80 MB。保存空间不足时仍允许当次播放，并提示无法持久保存的歌曲。
- 已验证 MP3、WAV。M4A、FLAC、OGG、AAC 等按浏览器的解码能力工作，无法解码时给出提示。
- 当前音源为本地文件与内置演示片段，尚未接入商业音乐平台。流媒体载体同样播放这些音源。

音频不上传；页面、字体、封面和演示音频均随应用提供。

## 操作与动态效果

底部始终保留播放、进度、音量、切歌、随机和循环入口。背景区域的快捷键：空格播放/暂停，左右方向键前后五秒，M 静音。编辑输入框或操作设备时，快捷键让位于当前控件。

换载体时，旧设备先轻颤、亮出裂纹，再炸成带 3D 翻转的真实碎片和粒子；新设备的碎片从四周飞回、拼合后由真实设备接管，全程约 1.2 秒。碎片是设备界面本身的克隆，所以每种载体都按自己的样子碎开。音频不等待动画；连续切换时，正在飞回的碎片会就地再次炸开，最终落在最后的选择上。首次打开页面时，设备从粒子中拼合出现。同年代内切歌不触发爆炸。

收音机旋钮支持拖动与方向键；调谐时指针连续移动，松手或停顿片刻后才切歌。iPod 转盘支持拖动、方向键和独立按钮。所有可拖动的操作都有点按或键盘替代：唱臂可用 CUE 升降杆、点唱片或方向键操作，Relic 芯片可点按接入。

偏好设置提供「减少动态效果」和机械反馈声开关。开启「减少动态效果」时，换载体改为约 0.2 秒的淡入淡出，唱盘、光盘和卷轴不再旋转；系统层面开启减少动态效果时，换载体同样只做淡入淡出。机械反馈声默认关闭；开启后包括按键声、转盘咔哒声、落针声和收音机调谐时的电台噪声。

设备使用 CSS / SVG 的 2.5D 造型，波纹和神经脉冲由 Canvas 与 Web Audio 绘制。唱片高光、唱针、收音机喇叭与调谐指示灯随真实播放电平变化，暂停后回落。移动端年代轴可横向滑动，页面可纵向滚动找到完整播放控制。

## 验证与后续范围

14 项自动测试通过，生产构建通过。测试覆盖九个年代的边界与编号、再版优先级、无年份降级、人工修正、随机队列、重复导入与真实 WAV 标签。浏览器中已检查完整文件选择器导入、同曲换设备保留进度、MP3/WAV 播放、修正与收藏刷新恢复、错误文件提示、单曲循环、顺序播放到末尾停止、收音机调谐与旋钮、CD 开合以及 Relic 接入。CD 合盖只恢复开盖前正在播放的音乐；原本暂停的歌曲继续保持暂停。2026-10-20 新增的黑胶、爆炸转场和设备交互的验证见 `qa/验证记录.md`。

响应式检查包括 390 像素和 320 像素宽度，修正了设备居中与窄屏歌单溢出；这些是桌面浏览器的视口验证，手机真机和 Safari 仍需进一步验证。

开发验证页：<http://127.0.0.1:5173/qa/import-check.html>。它使用项目生成的五个固定样本，调用应用的同一套导入与存储模块，并提供只清理这五个样本的按钮。该页面和样本不进入生产构建。

后续可扩展音乐平台授权播放、更精细的三维材质和分享卡片。
